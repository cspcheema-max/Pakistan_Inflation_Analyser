# Pakistan Inflation & Economic Data Analyzer

## Project Overview

This project is a Python-based economic data analysis
application focused on Pakistan's economy.

It retrieves historical economic indicators from the
World Bank API, analyses the data, generates charts,
and exports results into CSV and Excel files.

## Economic Indicators

1. Annual Inflation Rate (%)
2. Annual GDP Growth Rate (%)

## Data Source

World Bank Open Data API

https://api.worldbank.org/

Country: Pakistan (PAK)

Historical period: 2000–2025

## Technologies Used

- Python
- Pandas
- Matplotlib
- Requests
- Openpyxl
- World Bank API

## Project Features

- Automatic retrieval of economic data
- Historical inflation analysis
- GDP growth analysis
- Average and maximum/minimum calculations
- Inflation and GDP growth correlation
- Economic trend visualisations
- CSV data export
- Excel report generation
